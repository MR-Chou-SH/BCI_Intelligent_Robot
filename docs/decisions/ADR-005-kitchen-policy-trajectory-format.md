# ADR-005：Kitchen 记录控制目标与关键状态

日期：2026-10-27。状态：采用。依据：用户明确要求动作采用 joint pos 和夹爪开度，仅保留初态、动作、关键状态，可重放、可验成功，不采图像。

## 决策

V3 以 25Hz 保存双臂 14 维目标关节位置和 2 维目标夹爪开度比例。保持原 500Hz 控制器、插值和偏置补偿算法；不再逐物理步记录带补偿的执行器输入。一次性保存完整初态、原控制器插值状态与缓存偏置、设备计时器。关键状态保留 25Hz qpos/qvel、物体位姿、任务标记和实际夹爪间距。

为了避免开度比例反算腱长的浮点末位损失在接触中放大，额外保留每动作两个精确原生夹爪值；它们属于重放编码，不是另一个训练动作。帧中 hold/cancel 用稀疏动作与一位插值重置表示。

在线与离线复用 `validation/success.py`。组合只记录技能的名称、起止 tick，离线重新检验初始条件、技能边界及最终子目标，不相信保存的 PASS。默认报告仅保留结果及文件身份；详细检查、RPC、物理日志、图片、checkpoint 均关闭。V2 历史文件只读兼容，不假设其动作等同 V3。

## 权衡与验证

保留完整 qpos/qvel 能覆盖自由物体和设备，支持 Unity 状态渲染及离线物理核对，省去完整接触日志。25Hz 动作加两个原生夹爪值的实际验证消除了早期纯开度往返导致的长任务重放漂移；苹果、香蕉清洗、汉堡加热及梨/热狗组合重放误差均为零。模型/控制语义及 MuJoCo 版本不一致时应明确拒绝强行复现。
