# 离线连续时钟、短停顿处理与小范围圆角

分支 `feature/data-collection-improve`，HEAD仍为 `89768588655a6abda722af2db38113ef37611198`；保留此前未提交实现和用户 `.gitignore` 修改，未提交/切分支。用户要求改善持物搬运、旋转与撤手停顿，谨慎处理水池和炉壁边缘。

## 修改

在已有动作后优化实验增加显式 `--continuous`，普通采集和原retime实验默认行为不变。完整首次备份、稀疏上下文、动作候选、同初态物理执行、最终录制/独立重放链保持。

- `planning/action_retiming.py`：在每个明确模式/技能区间内跨过≤10帧的内部静止段；按关节折线弧长分配时间，减少IK路点附近的速度低谷。夹爪动作、较长等待、事件边界、最终稳定和guarded gripper不删除。水龙头device允许连续时钟，门和按钮device仍保护。
- `planning/action_smoothing.py`：两次局部二项式圆角；源关节改变量≤0.008rad、TCP位置变化≤2mm。端点/夹爪/明确边界附近5帧及acquire/device路径不改形状。无法证明夹具净距就保留源点；携带物用临时刚体姿态副本检查候选/中点对夹具距离，不修改真实物体。
- `data/retiming_experiment.py`：接入可选连续模式，记录圆角接受/拒绝、最大偏移与临时携带检查数量；1倍对照始终为未经圆角的原动作，保持准确重建检验。

详见 [运行方式及边界](../kitchen_platform_v3_20261020/ACTION_RETIMING_EXPERIMENT_CN.md)。当前是保守的局部路径修改与重新定时，没有全局缩短空间路径，没有提高现有joint/TCP上限。控制帧的速度变化不保证加速度/jerk最优，关节弧长时钟也不等于设备铰链严格匀角速度。

## 停顿与边缘检查

banana seed0，以25Hz实测关节最大速度<0.01rad/s且实测夹爪变化<0.002m/s衡量近静止，按真实合同区间统计（不是仅看目标动作）：

| 阶段 | 上一轮总时长/近静止 | 本轮总时长/近静止 |
| --- | ---: | ---: |
| 第一段携带 | 4.36s / 0.48s | 3.60s / 0.12s |
| 第二段携带 | 12.76s / 0.72s | 10.68s / 0.12s |
| 水龙头device | 12.36s / 6.56s | 8.88s / 4.96s |
| 水果放篮release | 3.84s / 1.12s | 3.48s / 0.96s |
| 水果放盘release | 3.76s / 1.08s | 3.44s / 0.92s |

device内原有若干0.32–0.36s的角度间等待被跨过；开始约1.44s和中间约3.56s的较长等待仍保留，含抓持确认和清洗。release近静止中还有必要开爪和稳定等待，未宣称已全部去掉。

banana seed0接受1469个局部圆角样本、拒绝7个，最大TCP位置偏移约1.30mm，525个携带样本检查了临时载荷/夹具关系。原轨迹保留区包含净距不足的点，不绕过水池边缘检查。

额外离线检查前四个用例记录的25Hz状态原生robot/fixture接触深度：无几何对比原备份增加超过1mm；R5两例均未发现robot/fixture穿透，banana峰值约0.557→0.505mm，R1约0.276→0.276mm。索引为 `smoothing_fixture_audit_20261106.json`。这只是抽样审核，不包含帧间保证、全载荷动态碰撞证明或替代现有关闭的部分接触门禁。
