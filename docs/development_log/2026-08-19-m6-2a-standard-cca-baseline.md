# M6.2a — Dataset/Epoch Pipeline and Standard CCA Baseline

Date: 2026-08-19
Status: Implementation complete; real formal dataset run complete

## Design

M6.2a adds a reusable offline decoder boundary under `eeg.decoder`. The
loader reads the formal M6.1b ground truth, raw packet stream, derived
associations, completeness verifier output and session signal-quality summary.
It rejects incomplete datasets, invalid associations, inconsistent segment
evidence and out-of-range epochs. Each trial result retains its trial identity,
association sample indices and extracted raw sample range.

The first baseline uses the session's channels whose existing quality metadata
is exactly `usable`. For the formal session this selects CH2, CH3, CH4, CH5 and
CH7. This is a deterministic session-specific rule and is not selected using
classification accuracy.

## Fixed baseline configuration

Raw and decoder sample rate remain 1000 Hz; no resampling or filter is applied.
Each channel is demeaned over the extracted analysis interval. The fixed epoch
uses a 0.5 s onset guard (500 samples) followed by a 3.0 s analysis interval
(3000 samples) inside the nominal 4 s stimulation. Three sine/cosine harmonic
pairs are used for each of 7.2, 9.0 and 12.0 Hz. These choices are conservative
and auditable: the guard reduces onset contamination, the 3 s interval matches
the legacy active decoder window, and avoiding an unverified filter/resampling
dependency keeps this first Standard CCA baseline simple and reusable.

The legacy Drone2.1 implementation requested a 3 s window and separately added
a 0.14 s lag before its 250 Hz decoder window. Its `readFixedData` call uses
`winLEN + lag`, so the active call is 3 s after the lag, not a verified 2 s
formal baseline. M6.2a does not copy its 8–16 Hz candidate grid or timestamp
assumptions.

## Formal dataset result

The fixed pipeline recovered 30/30 epochs with class balance 10/10/10 and
produced 30/30 correct predictions (accuracy 1.0). Per-class accuracy was
LEFT 10/10, CENTER 10/10 and RIGHT 10/10; the confusion matrix is diagonal.
The true-frequency score was highest for every trial. Score margins were
positive for all trials, with the smallest margin approximately 0.04. This is
evidence that this session contains separable frequency information under this
fixed baseline, not a generalization or final performance claim.

The machine-readable result is generated by `eeg.decoder.cca_cli` and is kept
as a local analysis artifact rather than raw dataset content.

## Evidence boundary and unresolved issues

All epoch sample indices remain software-derived estimates. Hardware timing,
physical optical timing and the ND8 hardware sample anchor remain unverified.
The signal-quality summary remains an engineering quality check, not a medical
quality metric. This single 30-trial session is insufficient for statistical
or paper-level conclusions. FBCCA and broader characterization remain future
work.
