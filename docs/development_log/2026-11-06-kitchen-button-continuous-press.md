# 微波炉按钮连续按压与撤手

用户反馈微波炉按钮附近停顿长，希望夹爪闭合后直接按，并要求实际运行一条轨迹及渲染。分支 `feature/data-collection-improve`，HEAD仍为 `89768588655a6abda722af2db38113ef37611198`；保留原工作区和数据，未提交/切分支/更改模型。

## 原因与修改

旧 `heat_open` 在按钮前20mm处先等待机械臂到位，再逐0.5mm调用 `point()`；每个深度都做末端收敛，还额外等待0.08秒。按下后30mm撤手也按5mm分段并逐段等待，最后固定等待0.3秒。几何路点密度变成了反复停启。

新实现：

- 夹爪闭合后，先在副本中生成原几何接近路径及20mm外到6mm按压深度的IK路径，使用一个连续时钟；在接触边界切换device合同，不在该边界停车。
- 接触后每25Hz控制帧推进一次并查询实际设备激活状态；一旦真实按钮位移/接触力触发加热立即停止继续加深，进入撤手。最大深度保持原6mm。
- 仅在尚未触发时允许末端最多8帧（0.32秒）预算覆盖原生50ms触发条件，没有每路点额外wait；未触发则明确失败。
- 撤手沿原方向30mm连续执行，保留终点到位和原end_contact检查，去掉固定0.3秒等待。
- 原模拟5秒加热计时继续执行；关门后到按钮、按钮到开门等几何不可行时的既有home回退仍记录原因，本轮不改变这些路径选择。

模型、控制器硬限速、按钮触发位移/力/持续时间与任务成功标准均未改变。实现位于 `integration/kitchen/planning/expert.py` 的 `heat_open`、`press_button_continuously` 和 `execute_button_targets`。
