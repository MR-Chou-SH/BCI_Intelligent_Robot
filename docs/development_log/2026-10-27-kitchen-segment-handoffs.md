# 入炉与关门之间的连续运动（2026-10-27）

用户确认先合并现有几何路线、统一连续段时序，减少段间停顿，再逐步考虑拐角平滑。本轮针对主食入炉，以及释放后撤手接近关门位置两条链。

## 修改与边界

1. 炉前侧向走廊、炉前定位、降低高度、进入炉内、最终下降六段路径先合成一组笛卡尔采样姿态，完整求IK，再共享一个运动时钟。原来的五个内部段末收敛点取消；保留几何路线和最终放置收敛。
2. R1在释放成功后显式返回按几何计算的炉口退出姿态，再将它传给关门接近规划。退出和接近在脱离实时仿真的数据副本中分别完成几何规划，合并关节路径后只执行一次；退出点不再减速停下。无隐式待执行动作，主食单独入炉的准备流程仍会完成退出，避免把手留在炉内。
3. 合并接近规划失败时记录原因，先按原退出动作清空炉口，再重新规划门接近；不能从炉内直接尝试home回退。只在所有路线规划成功后开始执行合并路径。

释放确认、门接触前的收敛、原关节/TCP限速与任务成功门槛保留。默认记录仍为初态、动作和关键状态，不增加逐步检查数据。这里没有把抓放等接触状态切换也强行串成不停顿动作，也没有改视频播放时序。新路径仍保留原折线走廊；尚未增加会切过拐角净空的曲线平滑。

## 配对结果

research seed0、faster，比较上一版 `right_flow_pilot_20261027` 与本轮 `segment_flow_pilot_20261027`。两对初始完整物理状态逐元素相同，任务成功及独立动作重仿真均通过，最大qpos/qvel误差0。

| 指标 | 汉堡：上一版→本轮 | 热狗：上一版→本轮 |
| --- | ---: | ---: |
| R1装炉关门总时长 | 82.72→76.64秒 | 85.28→79.52秒 |
| 连续入炉路径时长 | 26.28→20.60秒 | 23.92→18.52秒 |
| 入炉内部指令近静止时间 | 6.44→0秒 | 6.92→0秒 |
| 入炉内部实测关节近静止时间 | 6.00→0.44秒 | 6.08→0.36秒 |

近静止统计：连续至少3个25Hz关键帧，指令最大关节步长小于 `1e-4 rad/帧`，实测最大关节速度小于 `.01 rad/s`；排除路径首尾各0.2秒。入炉统计区间从炉前走廊开始，到张开夹爪前的0.4秒支撑等待开始。实测仍有两次短减速，不宣称无任何停顿或加速度全程连续。`comparison.json` 保存统计定义、配对报告路径/哈希及重放结果。

71项测试通过，新增覆盖：退出与门接近先完整规划后只调用一次执行、规划失败先退出再尝试后续路线、R1显式传递退出姿态。原始数据及以前的视频保留，不进行覆盖。

本轮证据目录均在 `experiments/kitchen_platform_v3/collections/`：

- `segment_flow_pilot_20261027`：两种主食seed0配对采集及 `comparison.json`。
- `segment_flow_regression_20261027`：两种主食seed1的R1、汉堡seed1的R2、两种主食seed0的C04，以及苹果热狗seed0的D08。各报告记录实际结果；不能把这个有界回归当成全部100实例验收。

最终上述8个用例/seed全部通过在线任务成功与独立动作重放，qpos/qvel最大误差均为0；六项回归也没有触发 `route_via_fallback`。两种主食C04完整加热取餐分别为271.36/270.24秒。计划与同参数计划续跑均验证100实例、目标200条。

## 新采集

旧批次不能按新源码续跑。使用新目录，例如：

```bash
bash scripts/collect_kitchen_dataset.sh \
  --output experiments/kitchen_platform_v3/collections/all_tasks_segment_flow_20261027 \
  --motion-profile faster --samples-per-case 2 --jobs 2
```
